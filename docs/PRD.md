# HR 면접 질문 사전 — 제품 요구사항 문서 (PRD)

## 1. 프로젝트 개요

| 항목 | 내용 |
| --- | --- |
| **프로젝트명** | HR 면접 질문 사전 |
| **목적** | 면접관이 직무별 면접 질문을 빠르게 찾아볼 수 있는 웹앱 |
| **CMS 선택 이유** | Notion API를 활용하여 비개발자도 콘텐츠 관리 가능 |

### 한 줄 요약
> 면접관이 직무 카테고리로 질문을 빠르게 찾고, 질문의 의도와 좋은 답변 예시까지 한눈에 확인할 수 있는 서비스입니다.

---

## 2. 핵심 가치 (왜 만드나요?)

- 면접관이 매번 질문을 새로 고민하지 않고, **검증된 질문을 빠르게 재사용**할 수 있습니다.
- Notion을 콘텐츠 저장소로 사용해 **개발자가 아니어도 질문을 추가·수정**할 수 있습니다.
- 질문마다 **의도와 좋은 답변 예시**가 있어, 면접 경험이 적은 사람도 활용할 수 있습니다.

---

## 3. 주요 기능

| 우선순위 | 기능 | 설명 |
| --- | --- | --- |
| ⭐ 핵심 | **직무별 카테고리 필터링** | 인사/총무, 채용, 노무, 조직문화로 질문을 좁혀서 보기 |
| 높음 | **면접 질문 검색** | 키워드로 질문 찾기 |
| 높음 | **질문 상세 보기** | 질문 의도, 좋은 답변 예시, 난이도 확인 |
| 높음 | **반응형 디자인** | PC·태블릿·모바일에서 모두 보기 편하게 |

| 구분 | 기술 |

---

## 5. Notion 데이터베이스 구조

질문 하나하나가 Notion 데이터베이스의 한 줄(레코드)이 됩니다. 각 줄은 아래 속성들을 가집니다.

| 속성명 | 의미 | 타입 | 값 |
| --- | --- | --- | --- |
| `Title` | 질문 내용 | title | 자유 입력 |
| `Category` | 직무 카테고리 | select | 인사/총무, 채용, 노무, 조직문화 |
| `Difficulty` | 난이도 | select | 초급, 중급, 고급 |
| `Intent` | 질문 의도 | rich_text | 자유 입력 |
| `GoodAnswer` | 좋은 답변 예시 | rich_text | 자유 입력 |
| `Tags` | 태그 | multi_select | 자유 입력(여러 개) |
| `Status` | 상태 | select | 초안, 발행됨 |

> `Status`가 **발행됨**인 질문만 웹앱에 보여주는 방식으로, 작성 중인 초안은 숨길 수 있습니다.

## 7. MVP 범위

> **MVP**(Minimum Viable Product, 최소 기능 제품)는 "핵심 가치를 전달하는 데 꼭 필요한 최소한의 기능"만 담은 첫 버전을 뜻해요. 욕심내지 않고 가장 중요한 것부터 만듭니다.

### ✅ MVP에 포함
- Notion API 연동
- 질문 목록 + 카테고리 필터링
- 질문 상세 페이지
- 기본 스타일링 + 반응형

### ⏳ MVP 이후로 미룸 (Out of Scope)
- 면접 질문 검색 (MVP 다음 단계)
- 사용자 로그인 / 즐겨찾기
- 질문 즐겨찾기 · 북마크
- 다국어 지원

---

## 8. 구현 단계

1. **Notion API 패키지 설치 및 환경 설정** — `@notionhq/client` 설치, 환경 변수 준비
2. **Notion 데이터베이스 생성 및 API 키 설정** — 위 5번 구조대로 DB 생성, API 키 발급
3. **질문 목록 페이지 구현** — Notion에서 질문을 불러와 목록으로 표시
4. **질문 상세 페이지 구현** — 질문 의도·좋은 답변·난이도 표시
5. **카테고리 필터링 구현** — 핵심 기능, 직무별로 질문 좁혀 보기
6. **스타일링 및 최적화** — Tailwind·shadcn/ui로 다듬고 반응형 마무리

---

## 9. 성공 기준 (이 정도면 MVP 완성!)

- [ ] Notion에 질문을 추가하면 웹앱에 자동으로 반영된다.
- [ ] 카테고리를 선택하면 해당 직무 질문만 보인다.
- [ ] 질문을 클릭하면 의도·좋은 답변·난이도를 볼 수 있다.
- [ ] 모바일에서도 레이아웃이 깨지지 않는다.
